# Havenstone Management — website

Static site for Havenstone Management, a residential property manager in the
Phoenix metropolitan area.

- `index.html` — home: the portfolio, services, owner enquiries
- `vacancies.html` — currently available homes
- `faq.html` — resident FAQ
- `owners.html` — management services, fees, reporting schedule
- `assets/site.css` — the design system; no inline styles in the pages

Type is Fraunces over Archivo, loaded from Google Fonts. Property artwork is
inline SVG rather than photography. The site commits to a single light
appearance on purpose, so it renders the same everywhere.

Published with GitHub Pages from `main`.
